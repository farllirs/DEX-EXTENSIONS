# Visor de Imágenes

Visualiza imágenes directamente en el editor de DEX STUDIO.

## Características

- Soporte para formatos PNG, JPG, JPEG, GIF y SVG
- Previsualización inline al abrir archivos de imagen
- Se integra como una pestaña más del editor

## Uso

Simplemente abre un archivo de imagen desde el explorador de archivos. La imagen se mostrará automáticamente en una pestaña del editor en lugar del contenido binario.
