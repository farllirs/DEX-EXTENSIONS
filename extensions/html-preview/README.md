# Preview HTML

Previsualiza archivos HTML en una pestaña del editor.

## Características

- Renderizado en tiempo real de archivos HTML
- Botón de preview en la barra del editor al abrir archivos `.html`
- Vista previa en iframe aislado dentro del editor

## Uso

1. Abre un archivo `.html` en el editor
2. Haz clic en el botón de preview (icono de ojo) en la barra del editor
3. La previsualización se abrirá en una pestaña adyacente
