# Autocompletado

Sugerencias inteligentes de código mientras escribes.

## Características

- Autocompletado contextual para Python, JavaScript, HTML y CSS
- Diccionarios de palabras clave por lenguaje (carpeta `wordlists/`)
- Popup de sugerencias que aparece al escribir
- Navegación con flechas y selección con Enter/Tab

## Uso

La extensión se activa automáticamente al escribir en el editor. Las sugerencias aparecen basándose en el tipo de archivo abierto y las palabras clave disponibles en los wordlists.

## Wordlists

Los archivos en `wordlists/` contienen las palabras clave para cada lenguaje:
- `python.json` — Palabras clave de Python
- `javascript.json` — Palabras clave de JavaScript
- `html.json` — Tags y atributos HTML
- `css.json` — Propiedades y valores CSS
