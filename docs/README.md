# 📚 Documentación — DEX STUDIO Extensions

Guías y plantillas para crear extensiones para DEX STUDIO.

## Contenido

| Archivo | Descripción |
|---------|-------------|
| [GUIA-EXTENSIONES.md](GUIA-EXTENSIONES.md) | Guía completa para crear extensiones (estructura, API, temas, errores comunes) |
| [SDK-REFERENCE.md](SDK-REFERENCE.md) | Referencia completa de la API DEX SDK |
| [plantilla-extension.dex.js](plantilla-extension.dex.js) | Plantilla de código principal con todos los handlers documentados |
| [plantilla-manifest.json](plantilla-manifest.json) | Plantilla de manifest.json con todos los campos explicados |

## Inicio rápido

1. Copia `plantilla-manifest.json` y `plantilla-extension.dex.js` a una nueva carpeta
2. Renombra y edita los campos `{{PLACEHOLDER}}`
3. Asegúrate de que tu archivo JS termine con `// Dex code successful`
4. Copia la carpeta a `~/.dex-studio/extensions/`
5. Reinicia DEX STUDIO
